Pass by Reference & by value in Java
. In Java, primitive types (like int,double,boolean) are always passed by value, meaning a copy of the actual
  value is sent tot the method.
. For objects, Java passes a copy of the reference(not the object itself). This means both the original and
  the copied reference point to the same object in memory, so changes to the object inside the method affect
  the original.
. Key point: Java does not have true pass-by-reference liek C++, but object references passes by value can mimic
  similar behaviour.

Recursion in Java
. In Java, recursion is a programming technique where a method calls itself directly or indirectly to solve 
  a problem.
. The method that calls itself is called a recursive method.
. Recursion is often used for problems that can be broken down into smaller, similar sub-problems, such as
  factorial calcuation, Fibonacci series, tree traversal, and graph searches.
. A recursive method typically has two parts:
  . Base Case- The stopping condition that ends the recursion.
  . Recursive Case-
Memeory Allcoation in Recursion
. Each recursive call gets its own stack frame containing parameters, local variables, and return addresses.
. When the base case is reached, calls start returning, and stack frames are popepd off.
. For large inputs or deep recursion, consider iterative solutions or trail recursion optimization to avoid
  performance and memory issues.
Advantages and Disadvantages of Recursion
. Advantages
  .Cleaner,more intuitive code for inherently recursive problems(e.g., tree traversal).
  .Matches the natural structure of divide-and-conquer algorithms.
Disadvantages
. Higher memory usage due to multiple stack frames.
. Slower execution from repeated function calls.
. Risk of StackOVerflowError if base case is missing or recursion depth is too large.
"this" keyword in Java
. the "this" keyword is a reference variable that refers to the current object.
. It is used within an instance method or a constructor to refer to the current object whose method or constructo  r to the current object whose method or constructor is being called.
. The "this" keyword helps in distinguishing between instance variables and local variables with the same name,
  and it can also be used for various other purposes.
Advantages and Disadvantages of this Keyword.
* Advantages:
. Helps to distingush between instance variables and local variables with the same name.
. Can be used to pass the current object as an argument to another method.
. Can be used to return the current object from a method.
. Can be used to invoke a constructor form another overloaded constructor in the same class.
* Disadvantages:
. Overuse fo this can make the code harder to read and understand.
. Using this unnecessarily can add unnecessary overhead to the program.
. Using this in a static context results in a compile-time error.
Key uses of this Keyword.
Referring to Instance Variables: The most common use of the "this" keyword is to eliminate confusion between class arrtibutes and parameters with same name. For example:

Invoking Current Class Constructor: The "this" keyword can be used to call another constructor in the same class. This is known as explicit constructor invocation.
Returning the Current Class Instance: The "this" keyword can be used to reutrn the current class instance from a method.

Abstraction

Abstraction can be seen as the technique of filtering out the unnesessary details an object so that there remain only the useful characteristics that define it.
Abstraction focuses on perceived behavior of the entity. It provides and external view of the entity.

Abstract Classes in Java:
. An Abstract class is a class whose objects can't be created. An Abstract class is created through the use of the abstract keyword. It is used to represent a concept.
. An abstract class can have abstract methods (methods without body) as wella s non-abstract methods or concrete methods(methods with the body). A non-abstract class cannot have abstract methods.
. The clas has to be delcared as a abstract if it contains at least one abstract method.
. An abstract class does not allow you to create objects of its type. In this case, we can only use the objects of its subclass. 
. Using an abstract class, we can achieve 0 to 100% abstraction.
. There is always a default constructor in an abstract class, it can also have a parameterized constructor.
. THe abstract class can also contain final and static methods.
. Note: if any of the class is inhereting or using properties of abstract class i.e. extending abstract class the  n:
  a. the implementation/subclass must be defined as abstract or
  b. the implementation class must implement i.e. override all the abstract method of the abstract class.
Syntax of delcaring an abstract class:
 To declare an abstract class we use keyword abstract. The syntax is given below:
         abstract class className
         {
             //class body
         }
Abstract Methods in Java
. Abstract methdods are methods with no implementation and without a method body. They do not contain any method statement.
. An abstract method is delcared with an abstract keyword.
. The declaration of an abstract method must end with a semicolon;
. The child classes which inherit the abstract class must provide the implementation of these inherited abstract methods.
Syntax of delcaring abstract methods:
   access-specifier abstract return-type method-name();

. Encapsulation is one step beyond abstraction.
